## Git Workflow Reflection

During this project, I used Git and GitHub to manage and track my web development work. I first created a repository on GitHub and added a README file to describe the purpose of my project. I then created my project files and used GitHub Desktop to monitor the changes made to the repository. I made commits after completing important stages of the project so that my progress could be tracked. I also published the repository to GitHub using the main branch. One problem I experienced was understanding where to create and edit the project files because I was using GitHub Desktop instead of directly working on the GitHub website. I solved this by locating the local repository folder on my computer and creating the files there. This helped me understand how local files, commits and GitHub work together.
